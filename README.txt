TSR NEON SIGNATURE

Open TSR_Neon_Clickable_Preview.html for a locally clickable preview (located outside this ZIP).

The included HTML uses relative image paths and is not Gmail-ready until the PNG pieces are hosted on public HTTPS URLs. Gmail does not reliably support base64 embedded images or HTML image maps.

Upload each piece_*.png to an image host, replace each src="piece_*.png" in signature_hosting_template.html with its public HTTPS image URL, open the resulting HTML in Chrome, select the rendered signature table, copy, and paste into Gmail Settings > See all settings > General > Signature. Test by sending to another email account.

Banner is approximately 3:1 and may be wide on mobile.
